# Panduan Bendahara Pengeluaran Pembantu (`bpp`)

Tugas: mencatat pencairan, memverifikasi SPJ dan setoran sisa dana. Wajib MFA.

## 1. Mencatat pencairan
1. **Beranda → Menunggu tindakan** atau **Kegiatan → Pengajuan Kegiatan** → pengajuan berstatus **Disetujui**.
2. **Catat pencairan**: jenis pencairan, tanggal, jumlah, keterangan, dan tautan **bukti transfer** (centang akses
   terbatas). Σ pencairan tidak boleh melebihi total RAB.
3. Status menjadi **Dicairkan** dan **batas SPJ** terisi otomatis.
4. Salah catat? **Bendahara → Pencairan** → **Batalkan** dengan alasan (tidak dihapus).

Penyetuju akhir pengajuan tidak boleh mencatat pencairannya (pemisahan tugas).

## 2. Verifikasi SPJ
1. **Kegiatan → SPJ & Realisasi** → SPJ berstatus Diajukan.
2. Periksa setiap realisasi: **Buka berkas** untuk bukti; lengkapi nomor bukti setor pajak bila ada.
3. **Terima** atau **Kembalikan** (catatan wajib). Anda tidak dapat menerima SPJ yang Anda buat sendiri.

## 3. Verifikasi pengembalian sisa dana
1. **Bendahara → Pengembalian** → setoran berstatus Diajukan → cek bukti setor.
2. **Verifikasi** (bukti dibekukan; pengajuan selesai bila sisa nol) atau **Tolak** dengan catatan.

## 4. Laporan
**Laporan → Laporan**: LAP-04 (SPJ terlambat), LAP-05 (rekap potongan pajak — data informasi), LAP-06 (pengembalian).
