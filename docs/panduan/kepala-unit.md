# Panduan Ketua Prodi/Kepala Unit (`kepala-unit`)

Tugas: memverifikasi pengajuan unit Anda (tahap unit) dan memantau serapan unit.

## 1. Antrean verifikasi
1. **Beranda → Menunggu tindakan** menampilkan pengajuan unit Anda berstatus **Diajukan**.
2. Klik pengajuan untuk membuka rincian, RAB, dan **Tautan berkas** (TOR/KAK; klik **Buka berkas**).

## 2. Memutuskan
- **Verifikasi**: pengajuan lanjut ke tahap keuangan (catatan opsional).
- **Kembalikan**: wajib **Catatan (wajib)**; pengaju memperbaiki lalu mengajukan ulang.
- **Tolak**: wajib catatan; pengajuan berhenti.

Anda tidak dapat memverifikasi pengajuan yang Anda buat sendiri (pemisahan tugas).

## 3. Dasbor & laporan
1. **Beranda → Dasbor**: serapan unit, tren realisasi bulanan, SPJ jatuh tempo.
2. **Laporan → Laporan**: LAP-01 (realisasi), LAP-04 (SPJ terlambat), LAP-08 (penggunaan dana) untuk unit Anda;
   pilih format Excel/PDF.

## Tanya-jawab
- *Pengajuan unit lain tidak terlihat?* Benar — Anda hanya melihat unit sendiri.
