# Panduan Wakil Dekan bidang keuangan (`wadek-keuangan`)

Tugas: menetapkan pagu, menyetujui pengajuan & revisi (tahap akhir), membuka kunci periode, dan menutup tahun
anggaran. Wajib MFA.

## 1. Menetapkan pagu
**Anggaran → Pagu Unit** → pada baris pagu berstatus Draf klik **Tetapkan**. Pengajuan unit hanya dapat diajukan bila pagunya ditetapkan.

## 2. Persetujuan akhir
1. **Beranda → Menunggu tindakan** → pengajuan berstatus *Diverifikasi Keuangan*.
2. **Setujui** (sisa pagu dicek ulang), **Kembalikan**, atau **Tolak** (catatan wajib).
3. Revisi RAB: **Kegiatan → Revisi RAB** → **Bandingkan** → **Setujui**/**Kembalikan**/**Tolak**.
4. **Cetak PDF** pengajuan memuat kode QR verifikasi.

## 3. Membuka kunci periode
1. **Anggaran → Tahun Anggaran** → buka tahun → tab **Periode** → **Buka kunci** pada periode terkunci terbaru.
2. Isi alasan (minimal 20 karakter). Snapshot lama tetap tersimpan sampai dikunci ulang.

## 4. Menutup tahun anggaran
Setelah semua periode terkunci dan tidak ada pengajuan dalam proses: **Anggaran → Tahun Anggaran** → ubah status ke
**Ditutup**; centang konfirmasi bila masih ada pengajuan berstatus Dicairkan.

## 5. Dasbor & laporan
**Beranda → Dasbor** (seluruh unit) dan **Laporan → Laporan** (LAP-01, LAP-07 snapshot periode).
