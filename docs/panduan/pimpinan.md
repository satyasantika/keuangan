# Panduan Pimpinan/Dekanat (`pimpinan`)

Tugas: memantau anggaran dan realisasi seluruh unit (baca-saja).

## 1. Membaca dasbor
1. **Beranda → Dasbor**. Pilih **tahun** dan **periode** (bulanan/semester/tahunan) di filter atas.
2. **Ringkasan anggaran**: Pagu, Disetujui, Dicairkan, Realisasi, Serapan (realisasi kumulatif ÷ pagu).
   Baris *Honor ujian (impor fkipapp)* adalah rekap baca-saja dan tidak termasuk realisasi kegiatan.
3. **Serapan per unit** dan **Tren realisasi bulanan** untuk perbandingan antarunit.

## 2. Laporan
**Laporan → Laporan**: LAP-01 (Realisasi Anggaran per Unit) dan LAP-02 (Rekap Pengajuan per Status) → Excel/PDF.

## 3. Melihat rincian
**Kegiatan → Pengajuan Kegiatan** → buka pengajuan untuk melihat RAB dan riwayat persetujuan.
